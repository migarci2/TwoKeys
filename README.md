# TwoKeys

**No agreement, no action.**

TwoKeys is an AI agent for shared decisions. It preserves each participant's
context, surfaces unresolved disagreement, and blocks shared action until both
people approve the exact same proposal.

The initial demo uses a school notice as a compact scenario. The product is not
a school-permission manager; it addresses AI's single-player problem.
